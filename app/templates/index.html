About CarValueAI

📋 Dataset

This model is trained on the CarDekho "Car details v3" dataset from Kaggle, containing ~8,000 used-car listings from the Indian market with details like brand, year, mileage, engine specs, and selling price.

🔬 Method

  • Regression: We compare Linear Regression, Ridge, Random Forest, and XGBoost. The best model (tuned via RandomizedSearchCV with 5-fold CV) predicts the log-transformed selling price, which is then converted back to INR.
  • Classification: Out-of-fold regression predictions create deal labels (Underpriced / Fair / Overpriced based on actual/predicted ratio). A classifier trained on car features + listed price predicts the deal category.
  • Explainability: SHAP (SHapley Additive exPlanations) values reveal which features most influence each prediction.

⚠️ Limitations

  • The model is trained on CarDekho data only — real market prices vary by location, condition, and negotiation.
  • Exotic or rare car models may not have enough training examples for reliable estimates.
  • The dataset has a fixed time horizon; used-car prices fluctuate with economic conditions.
  • Features like service history, accident record, and modifications are not captured in this dataset.
